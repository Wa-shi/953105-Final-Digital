กับดักสูตร
  • ลำดับ VLOOKUP = ค่าที่หา, ตาราง, เลขคอลัมน์, FALSE ตัวลวงชอบสลับ
  • ID ใช้ FALSE (exact) · TRUE = approximate ต้องเรียงข้อมูลก่อน
  • col = 1 ได้ค่าที่หาเองกลับมา
  • "มากกว่า 7" = C2>7 ไม่ใช่ C2<7
  • IFERROR จับแค่ error ไม่ได้เช็กคำว่า Fail
  • FIND คืนตัวเลข ไม่ใช่ TRUE ไม่ใช่คำ
