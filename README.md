# 953105 Final Digital

สื่อทบทวนไฟนอลวิชา SE105 (953105) Digital Proficiency for Software Engineering ครอบคลุมบทที่ 7 ถึง 12 และ Quiz 8 ถึง 13

## เว็บติว

เปิดผ่าน GitHub Pages ของ repo นี้ มี 6 แท็บ

- **ติวจากศูนย์** อธิบายทุกกล่องในชีทสอบ พร้อมตัวอย่างและคำถามลองตอบ
- **ศัพท์และสัญลักษณ์** ตารางคำศัพท์ที่ค้นหาได้
- **อธิบายชีท** บอกว่าแต่ละกล่องในชีทใช้ตอบข้อสอบแบบไหน
- **แนวข้อสอบรายบท** เรื่องที่ออกบ่อย กับดัก และข้อ Quiz พร้อมเหตุผล
- **เครื่องมือ** Excel formula lab, Cyber attack matcher, Citation builder IEEE และ APA
- **แบบฝึกหัด** ข้อใหม่ 42 ข้อ
